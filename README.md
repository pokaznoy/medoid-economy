## Як працює проєкт

Проєкт складається з відкритого сайту-каталогу та Google Sheets, куди потрапляють заявки з Google Form.

### Файли проєкту

- `index.html` — головна сторінка сайту. Містить структуру сторінки, заголовок, кнопку додавання бізнесу, поле пошуку, блок фільтрів, список карток і футер.
- `data.js` — файл з даними каталогу. У ньому зберігається масив `medoids` з усіма бізнесами та проєктами.
- `app.js` — логіка сайту. Відповідає за пошук, фільтрацію за категоріями та виведення карток на сторінку.
- `medoid-apps-script.gs` — Google Apps Script, який читає дані з Google Sheets і автоматично оновлює `data.js` у GitHub.
- `README.md` — опис проєкту.

### Схема роботи

1. Людина заповнює Google Form.
2. Відповідь потрапляє в Google Sheets.
3. Apps Script читає таблицю.
4. Скрипт формує новий вміст файлу `data.js`.
5. Через GitHub API файл `data.js` оновлюється в репозиторії.
6. Сайт підтягує оновлений `data.js` і показує нові записи в каталозі.

### Поля таблиці

Скрипт бере дані з таких колонок:

- B — назва бізнесу
- C — власник
- D — категорія
- E — опис
- F — контактне посилання

Якщо назва бізнесу або категорія порожні, такий запис не додається до каталогу.
