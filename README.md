# 🦡 Економіка Медоїдів

Це відкритий каталог бізнесів та послуг учасників спільноти.

### 🎯 Мета проекту
Створити зручний та прозорий інструмент, який допоможе «медоїдам» знаходити послуги один одного, зміцнюючи економіку довіри.

### 🛠 Технології
* **HTML/JS** — фронтенд.
* **Tailwind CSS** — оформлення.
* **Open Data** — дані зберігаються у відкритому доступі.

### 🤝 Як потрапити в каталог?
Надішліть свої дані в чат спільноти або створіть Pull Request до цього репозиторію.
